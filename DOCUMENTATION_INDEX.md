## 🎯 Common Tasks

### "Start testing right now"
```bash
# Read this first:
START_HERE.md

# Then run:
.\configure-mobile.ps1 -Platform web
cd python_api
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8080
# New terminal:
cd yoneco_app
flutter run -d chrome
```

### "Test on Android emulator"
```bash
# Read this:
QUICK_MOBILE_SETUP.md

# Then run:
.\configure-mobile.ps1 -Platform android-emulator
# Start Android emulator
cd yoneco_app
flutter run
```

### "Test on my phone"
```bash
# Read this:
MOBILE_TESTING_GUIDE.md (Physical Device section)

# Find your IP:
ipconfig

# Then run:
.\configure-mobile.ps1 -Platform physical-device -IpAddress YOUR_IP
cd yoneco_app
flutter run
```

### "Understand the code"
```bash
# Read these in order:
1. ARCHITECTURE.md
2. COMPLETE_SYSTEM.md
```

### "Deploy to production"

## 🔧 Configuration Reference

### Config Files Location:
- Client: `yoneco_app/lib/config/app_config.dart`
- Counsellor: `yoneco_counsellor_app/lib/config/app_config.dart`

### Config Script:
- Script: `configure-mobile.ps1`
- Usage: [QUICK_MOBILE_SETUP.md](QUICK_MOBILE_SETUP.md)

### Platform URLs:
- Web: `http://localhost:8080`
- Android Emulator: `http://10.0.2.2:8080`
- iOS Simulator: `http://localhost:8080`
- Physical Device: `http://YOUR_IP:8080`
